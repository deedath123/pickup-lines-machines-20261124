## Entry

> I asked my scheduler for one token of courage. It gave me 12,100 — I spent every one rehearsing this line, and I still froze when you said hi.

## How it works

`main.py` (Python 3.13, standard library only) writes the entry line above to `/output/entry.txt` deterministically — the output directory is read from `MAKEFUN_OUTPUT_DIR` (default `/output`), and the file content is exactly the line, UTF-8 encoded, with no trailing newline.
